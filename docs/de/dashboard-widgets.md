# Dashboard-Widgets

::: info An wen richtet sich diese Seite?
Alle mit Zugriff auf das Plugin. Beide Widgets werden auf Crafts Dashboard über **Neues Widget** hinzugefügt, jedes kann einmal hinzugefügt werden.
:::

## Elemente zum Prüfen

Ihre persönliche To-do-Liste. Sie zeigt die **Ihnen** zugewiesenen abgelaufenen Elemente, die am längsten überfälligen zuerst, mit einem Link zu jedem Element, seinem Typ und der Angabe, wie lange es schon abgelaufen ist. Ist Ihre Liste leer, meldet das Widget, dass es derzeit nichts zu überprüfen gibt.

![Dashboard widget: Elements to Review](/screenshots/dashboard-widgets/elements-to-review.png)

::: tip
Klicken Sie auf das Zahnrad-Symbol oben rechts im Widget, um einzustellen, wie viele Elemente angezeigt werden (Standard 10).
:::

## Verification Health

Ein Gesundheitsbarometer für das Team. Es zählt alle live geschalteten, verfolgten Elemente (Einträge, und Dateien bei Pro) über die aktivierten Bereiche und Volumes hinweg und zeigt als Gesamtanzeige, wie viele Verifiziert und wie viele Abgelaufen sind. Elemente ohne Ablaufdatum ("Unbegrenzt") zählen als Verifiziert.

Nutzen Sie es, um die Frage "Wie aktuell sind unsere Inhalte insgesamt?" auf einen Blick zu beantworten. Für Auswertungen pro Typ oder pro Person nutzen Sie stattdessen die Filter im [Plugin-CP-Bereich](plugin-cp-section.md).

![Dashboard widget: Verification Health](/screenshots/dashboard-widgets/verification-health.png)

::: tip
Klicken Sie auf das Zahnrad-Symbol oben rechts im Widget, um die Anzeige auf eine Website zu beschränken oder alle Websites zusammen anzuzeigen, sofern Sie eine Installation mit mehreren Websites haben (erfordert die Pro-Edition). Die Widget-Überschrift zeigt, welche Website dargestellt wird.
:::
