# Control-Panel-Lokalisierung

::: info An wen richtet sich diese Seite?
Administratoren, die Verified Elements für mehrsprachige Teams einrichten.
:::

Alles, was das Plugin zu Craft hinzufügt (Beschriftungen, Schaltflächen, Status-Badges und Benachrichtigungs-E-Mails), wurde in die folgenden Sprachen übersetzt:

|---------------------|------------|
| Dänisch             | `da`       |
| Deutsch             | `de`       |
| Englisch            | `en`       |
| Französisch         | `fr`       |
| Italienisch         | `it`       |
| Norwegisch (Bokmål) | `nb`       |
| Polnisch            | `pl`       |
| Portugiesisch       | `pt`       |
| Russisch            | `ru`       |
| Schwedisch          | `sv`       |
| Spanisch            | `es`       |
| Tschechisch         | `cs`       |
| Türkisch            | `tr`       |
| Ukrainisch          | `uk`       |
