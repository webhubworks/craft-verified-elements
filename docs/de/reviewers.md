# Arbeiten als Prüfer

::: info Zielgruppe
Alle, die als Prüfer eingesetzt wurden. Prüfer zu sein ist eine Zuweisung, keine Berechtigung. Ihnen können Elemente zugewiesen werden, auch wenn Sie sie selbst nicht verifizieren dürfen. In dem Fall prüfen Sie den Inhalt und ein Kollege mit der Verifizierungs-Berechtigung bestätigt ihn.
:::

## Was es bedeutet, Prüfer zu sein

Wenn Sie jemand als Prüfer eines Eintrags oder einer Datei einsetzt, werden Sie dafür verantwortlich, das Element erneut zu kontrollieren:

- Wenn das "Verifiziert bis"-Datum überschritten wird, erhalten Sie eine **E-Mail-Zusammenfassung** mit allem, was von Ihren Elementen abgelaufen ist.
- Wenn das Element geändert wird, während es verifiziert ist, erhalten Sie eine **Änderungshinweis-E-Mail**, damit Sie die Änderungen nachprüfen können.
- Das Element erscheint in Ihrer persönlichen Prüfliste (siehe unten), bis es wieder verifiziert ist.

## Wo Sie Ihre Prüfliste finden

Sie haben drei Ansichten auf dieselbe Liste:

### 1. Ihre Kontoseite

Gehen Sie zu **Mein Konto → Verifizierung**. Diese Seite listet alle Ihnen zugewiesenen Elemente, mit Tabs für Einträge und Dateien (Pro) und Spalten für Status, Website, Bereich oder Volume, "Verifiziert bis" und die letzte Aktualisierung. Administratoren können dieselbe Seite im Profil jedes Benutzers öffnen, um dessen Zuweisungen zu sehen.

### 2. Das Dashboard-Widget "Elemente zum Prüfen"

Fügen Sie es zu Ihrem Craft-Dashboard hinzu. Es listet Ihre abgelaufenen Elemente, die am längsten überfälligen zuerst. Siehe [Dashboard-Widgets](dashboard-widgets.md).

### 3. Der Bereich des Plugins

Im Bereich **Verifizierung** hat die Seitenleiste einen Filter mit Ihrem Namen, der alles zeigt, was Ihnen zugewiesen ist, unabhängig vom Status. Siehe [Der Verifizierungs-Bereich](verified-elements-section.md).

## So entfernen Sie ein Element aus Ihrer Liste

1. Öffnen Sie das Element aus der Liste, dem Widget oder dem E-Mail-Link.
2. Prüfen Sie den Inhalt. Aktualisieren Sie, was veraltet ist.
3. Setzen Sie im Verifizierungs-Panel ein neues "Verifiziert bis"-Datum (oder bitten Sie jemanden mit der Verifizierungs-Berechtigung darum, oder nutzen Sie die Massenaktion **Verifizieren** aus einer Liste).
4. Speichern Sie. Das Element ist wieder Verifiziert und verschwindet aus Ihrer Liste.

Ist der Inhalt dauerhaft korrekt, wählen Sie **Unbegrenzt**. Er kommt dann nie wieder in Ihre Liste.

Sind Sie nicht mehr die richtige Person, weisen Sie im Verifizierungs-Panel einen anderen Prüfer zu, oder bitten Sie einen Administrator, das Element mit der Massenaktion **Prüfer zuweisen** neu zu vergeben.

## Wenn Sie das Team verlassen oder deaktiviert werden

Wird das Benutzerkonto eines Prüfers deaktiviert oder gelöscht, werden seine abgelaufenen Elemente wie nicht zugewiesene behandelt: Die Ablaufberichte gehen an die System-E-Mail-Adresse der Website, bis jemand sie neu zuweist. Administratoren sollten nach Teamänderungen den Filter **Unbestimmt** im Blick behalten.
